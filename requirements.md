### **🎯 Goal**

Create a simple service for storing files, with the ability to manage and edit them. All data should be synchronized between users of the system. The system should also include basic permissions management for file or folder access. Additionally, there should be the ability to share file access via email with specific permissions (similar to Google Drive).

### 📦 Delivery

- **Short demo video**: demonstrate the app functionality and explain structure/architecture approaches of the codebase, with description in English
- GitHub repository
- `README.md` file with clear setup and run instructions _(mark in the middle of README which AI model was used for vibe coding)_
- _No deployment required_

---

### **🧰 Technologies**

**Frontend**

- React.js + TypeScript
- Can be implemented with **plain React** or a **meta-framework** built on top of it (e.g., **Next.js**, **TanStack Start**)
- Additional libraries if needed (e.g., Axios, React Query, Apollo, etc.)

**Backend**

- Nest.js
- RESTful / GraphQL API
- Implement requests to the database directly in the Controllers
- OpenAPI documentation (REST API only)

### **✅ Checkpoints**

- Simple authentication
- Simple UI
- File upload functionality
- Support for a hierarchical folder system (nested folders and files)
- Reordering of files and folders
- Unit tests coverage (jsest)
- File and folder management: clone, remove, rename, and edit (optional)
- Search files and folders by name
- Public or private file visibility
- File viewing accessibility management (public/private) (optional)
- Ability to grant users access via email with specific permissions (optional)
- Viewing shared files or folders through a public link (optional)
- Background jobs for compressing videos and images (optional)
